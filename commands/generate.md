# tose generate

Generate a Dockerfile for your project using AI.

## Synopsis

```bash
tose generate [-o <path>] [--overwrite] [--skip-commit] [--auto-commit] [--auto-push]
```

## Description

Scans your project source code, detects the language, framework, and package manager, then uses AI to generate an optimized Dockerfile. The generated Dockerfile is tailored to your project's stack and follows best practices for production deployments.

## Options

| Option | Description |
|--------|-------------|
| `-o, --output <path>` | Output file path (default: `Dockerfile`) |
| `--overwrite` | Overwrite existing Dockerfile |
| `--skip-commit` | Skip the git commit prompt |
| `--auto-commit` | Automatically commit without prompting |
| `--auto-push` | Automatically push after commit |

### Overwrite Existing Dockerfile

```bash
$ tose generate --overwrite

Scanning source code...
✓ Source code scanned
  Language: Python
  Framework: FastAPI
  Package Manager: pip

Generating Dockerfile with AI...
✓ Dockerfile generated
```

### Custom Output Path

```bash
$ tose generate -o docker/Dockerfile.prod
```

### Skip Git Commit

```bash
$ tose generate --skip-commit
```

### Auto Commit and Push

```bash
$ tose generate --auto-commit --auto-push
```

## How It Works

1. **Scan** - Reads key project files (package.json, config files, directory structure)
2. **Detect** - Identifies language, framework, and package manager
3. **Generate** - Sends project context to the TOSE AI API
4. **Save** - Writes the generated Dockerfile to disk
5. **Commit** (optional) - Commits the Dockerfile with message `Add Dockerfile (generated by tose)`

::: tip
The generated Dockerfile is a starting point. Review it and customize for your specific needs, especially for production deployments.
:::
